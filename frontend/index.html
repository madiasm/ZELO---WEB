Sobre o projeto

Aplicação web feita para o trabalho prático de contêineres. Ela é uma versão web do ZELO, aplicativo desenvolvido no TCC de Ciência da Computação.

  • Frontend: HTML, CSS e JavaScript e é entregue pelo Nginx (servidor web).
  • Backend: API em Python com Flask.
  • Banco de dados: PostgreSQL, com volume para manter os dados.
  • Orquestração: Docker Compose, com rede própria e variáveis de ambiente.
